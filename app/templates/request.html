Как подключить Element X на Android и iPhone

После одобрения заявки администратор предоставит логин и пароль для корпоративного мессенджера.

  1. Установите Element X: Android (Google Play) или iPhone (App Store).
  2. Выберите сервер. Нажмите «Войти», затем «Изменить сервер» / «Change account provider». Введите {{ matrix_homeserver }} (не matrix.org).
  3. Войдите. Укажите выданные администратором логин и пароль. Например, для логина ivanov.i полный Matrix ID — @ivanov.i:{{ matrix_server_name }}.
  4. Настройте восстановление. Если Element X предложит Recovery Key, сохраните его в безопасном месте. При входе со второго устройства может потребоваться подтверждение.
  5. Разрешите уведомления в настройках телефона, чтобы получать сообщения вовремя.

Открыть Element X с нашим сервером ↗

Для входа нужна одобренная заявка. Не создавайте отдельную учётную запись на matrix.org.
